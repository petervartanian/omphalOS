The approximately 16 MB deployment contains application code and runtime assets only. A complete workspace backup downloaded and restored successfully, including the saved review and package. A second tab was prevented from opening a conflicting writer.

The full-list acceptance pass exposed repeated source parsing and credential scans that smaller fixtures did not reveal. Bounded caches now reuse only immutable validation results keyed by the actual content hashes. Every load still hashes the files, and each loaded source returns a fresh dictionary. Credential scanning first locates candidate key spellings, then applies the unchanged full matching rule; 5,000 deterministic adversarial comparisons and Unicode/boundary tests guard equivalence. Regression tests cover altered bytes with preserved timestamps, changed normalized data and hashes, changed evidence references, mutable caller data, and scanner-rule changes.

In an isolated comparison using the same 26,154-entry CSL snapshot under the actual Node-hosted WebAssembly runtime, export decreased from 21.84 to 14.92 seconds and the following reopen from 11.87 to 3.42 seconds. Both packages verified. These measurements exclude browser persistence and do not establish identical timing on other devices.

Browser storage is subject to quotas, eviction, and user deletion. Persistence failures retain the in-memory result, show a persistent backup warning, and do not disable read/download operations. A failed initial storage read blocks startup. Backup restoration has an explicit confirmation and blocking progress dialog. The browser edition does not include native detached Ed25519 signature verification; direct OFAC downloads require file import because of the publisher's browser-access policy. Current evidence establishes the tested Chromium-based browser workflow, not all browser versions or unlimited dataset scale.

The final integrated browser/backend suite passed 743 tests, including 14 renderer tests. Cross-platform CI exposed two Windows portability issues: an oversized fixture name and missing system font MIME registration. Short parameter IDs and explicit packaged-asset content types address them; targeted tests exercise the missing MIME registry. The Package lid is pearl with a rainbow reflection before completion. Verified export transforms every panel to a dark ink base, continuous rainbow sheen, and fine engraved pattern; changing the assessment restores the I–V stage pigments and VI's light finish. Source records and computational findings are not changed by the visual state.

The audit fixed several concrete sources of false observations. Placeholder or punctuation-only address, payment-method, broker, domain, and unit values no longer count as usable context for the affected checks. Coverage states when values were excluded and reports a check as not evaluable when no usable records remain. Original values stay in the evidence. Sentinel handling is field-specific: the country code `NA`, identifiers such as `NA-123`, and the case-sensitive SI unit `nA` are preserved. Case and punctuation variants of the same domain label no longer count as different domains.

Paid-value cohorts now preserve unit-label case: `mg` and `Mg` cannot be merged into a supposedly comparable cohort. A regression verifies both the absence of a false cross-unit outlier and detection of a real outlier within one matching cohort. Unit aliases are not automatically reconciled, and no conversion is inferred.

CSL imports reject malformed name, entity-type, identifier, address, and unsupported date formats at import. Contradictory but individually valid dates are retained with explicit diagnostics, as documented in the follow-up below. Source dates and other metadata derived from the source must reproduce from the retained raw snapshot; changing normalized metadata and its hashes together is insufficient. Archived runs expose verified entity names and source attribution from their own retained evidence, even when the original workspace inventory entries are gone. Saved direct-name intakes carry a marker so reopening them can resume public identity research instead of silently skipping that stage.

Assessment is now a case-level decision with an optional case note and directly accessible evidence tables. The case review's scope identifies the included observations; it does not assert that a separate disposition was entered for every observation. Export retains original analytical findings, limitations, evidence, and the actual saved human decision. Legacy per-observation reviews remain readable.
